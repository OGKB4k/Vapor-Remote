Controller Guide

1. Activation & Pairing

Ensure your vaporizer has sufficient charge and your device's Bluetooth is enabled. Place and hold your fingers on the device's touch sensor pads until the LED indicator blinks green, then release to enter pairing mode.

Click the "CONNECT" button in this application and select your hardware. The LED will blink blue to confirm a successful link.
2. Thermal Control

Select a Standard Preset, or use the Pro Dial for 10°F precision adjustments. Upon selection, the hardware LED will blink green to confirm the new thermal target has been engaged.

CAUTION: Setting the temperature above 450°F (Concentrates mode) will cause combustion if used with dry botanical material. Adjust carefully.
ABOUT THIS PROJECT
This application is a community-driven passion project. While the original manufacturer continues to innovate with excellent new devices, changes in legacy app availability left some users unable to access their older device's precision tuning features.

To keep this great hardware running strong, this lightweight, open-source-style web controller was built. It runs entirely in your browser using Web Bluetooth. It is completely offline, privacy-first, and requires no servers.

This software is offered completely free, as-is, as a gift to the community. If you found it useful and want to support my work and other projects, I would greatly appreciate it.
