# Vapor-Remote
Vaporizer Remote

https://ogkb4k.github.io/Vapor-Remote/

This application is a community-driven passion project. While the original manufacturer continues to innovate with excellent new devices(3rd gen announced), changes in legacy app availability left some users unable to access their older device's precision tuning features.

To keep this great hardware running strong, this lightweight, open-source-style web controller was built. It runs entirely in your browser using Web Bluetooth. It is completely offline, privacy-first, and requires no servers.

This software is offered completely free, as-is, as a gift to the community. If you found it useful and want to support my work and other projects, I would greatly appreciate it.
