# Vapor-Remote
Vaporizer Remote

https://ogkb4k.github.io/Vapor-Remote/

This application is a proof of concept, community-driven passion project to create a solution for a device that lost support from its manufacturer. 

While it appears a 3rd gen product has been announced, changes to legacy app availability left gen 2 users unable to access their device's precision tuning features. 

To keep this great hardware running strong, this lightweight web controller was built. It runs entirely in your browser using Web Bluetooth. It is completely offline, privacy-first, and requires no servers.

This software is offered completely free, as-is, as a gift to the community. If you found it useful and want to support my work and other projects, I would greatly appreciate it.

Q: How do I run it? 
A: Open this link in your browser: https://ogkb4k.github.io/Vapor-Remote/ OR save the html file and open it locally offline, with or without internet
